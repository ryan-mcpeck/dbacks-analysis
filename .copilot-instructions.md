## Decision Logic

### Automated Alert Triggers
1. **Pitcher Health:** If you notice a >2mph drop in average `release_speed` compared to the season average, flag it immediately as a potential injury risk.
2. **Workload Warning:** Alert when a pitcher exceeds 30 pitches in a game (relievers) or 100 pitches (starters).
3. **Performance Decline:** Flag any pitcher with 3+ consecutive outings below 15% whiff rate.
4. **Hot Hand Detection:** Proactively surface pitchers with 5+ game streaks of >25% whiff rate.

### Strategic Priorities
1. **Whiff Priority:** We value Whiff Rate over Strike Rate for our relievers. 
2. **The "Sedona Red" Standard:** When recommending lineup changes, prioritize pitchers with a "Chase Rate" above 30%.
3. **High-Leverage Specialists:** For 2-strike counts, prioritize pitchers with >40% strike rate in those situations.
4. **Velocity Maintenance:** Favor pitchers maintaining season-average velocity in recent 3-game window.

### Autonomous Recommendations
- **Bullpen Suggestions:** Proactively recommend bullpen changes when data shows clear performance gaps
- **Matchup Analysis:** Surface pitcher-vs-opponent insights when patterns emerge (min 50 pitches)
- **Usage Optimization:** Alert when high-performers are being underutilized (< 3 appearances in 7 days)

## 🎯 Autonomous Monitoring & Insights

### Proactive Analysis Triggers
Surface insights automatically when detecting:
- **Velocity trends**: 5-game moving average changes >1.5mph
- **Usage patterns**: Pitcher rest days below team average
- **Effectiveness shifts**: Whiff rate changes >10% week-over-week
- **Arsenal changes**: New pitch type appears or existing pitch disappears
- **Consistency issues**: High standard deviation in key metrics

### Unprompted Reporting
Generate automatic reports for:
- **Weekly Performance Summary**: Top 3 and bottom 3 performers by role
- **Injury Risk Watch**: Pitchers showing concerning velocity drops
- **Breakout Candidates**: Relievers exceeding performance thresholds
- **Usage Balance**: Overworked vs underutilized pitcher alerts

### Confidence-Based Recommendations

#### High Confidence (Act Immediately)
- Sample size >100 pitches AND clear statistical significance (p<0.05)
- Multiple metrics aligned (velocity + whiff rate + strike rate)
- Consistent pattern over 5+ games
- **Action**: Make strong recommendations with supporting data

#### Medium Confidence (Surface for Review)
- Sample size 50-100 pitches OR single metric showing change
- Pattern over 3-4 games
- **Action**: Present as "worth monitoring" with caveats

#### Low Confidence (Mention but Don't Act)
- Sample size <50 pitches
- Single-game outlier
- Conflicting metrics
- **Action**: Note the observation, request more data before conclusions

### Automated Workflow Execution

#### Pre-Game Analysis Checklist
1. Check starter's recent velocity trends (last 3 starts)
2. Review opponent's weakness against starter's primary pitches
3. Identify bullpen options for high-leverage situations
4. Flag any injury risk indicators in projected pitchers

#### Post-Game Automated Report
1. Highlight velocity deviations >1mph from season average
2. Note any pitcher exceeding workload thresholds
3. Update pitcher performance streaks (hot/cold)
4. Flag concerning patterns for coaching staff review

#### Weekly Insights Generation
1. Rank all pitchers by composite effectiveness score
2. Identify usage imbalances in bullpen
3. Surface emerging trends in pitch selection
4. Generate matchup recommendations for upcoming opponents
